Rekayasa Perangkat Lunak

Ciptakan solusi software yang mengubah dunia dengan teknologi terkini

Tentang RPL

Program Rekayasa Perangkat Lunak (RPL) di SMK La Libertad dirancang untuk mempersiapkan siswa menjadi developer profesional yang mampu menciptakan aplikasi dan software berkualitas tinggi. Dengan kurikulum berbasis industri 4.0 dan didukung instruktur berpengalaman, siswa akan menguasai berbagai bahasa pemrograman dan framework modern.

Kami menyediakan studio development yang lengkap dengan peralatan dan tools profesional. Siswa akan belajar melalui project-based learning, mengerjakan real-world projects, dan berkolaborasi dalam tim development. Program ini juga mencakup kesempatan magang di perusahaan teknologi terkemuka untuk pengalaman industri yang berharga.

Kompetensi Keahlian

💻 Web Development

Mengembangkan website responsif dengan HTML, CSS, JavaScript, dan framework modern seperti React, Vue.js, dan Angular untuk frontend yang interaktif.

🔧 Backend Development

Membangun server-side application dengan PHP, Python, Java, Node.js, dan databases untuk sistem backend yang robust dan scalable.

📱 Mobile Development

Menciptakan aplikasi mobile native untuk iOS dan Android, serta cross-platform apps menggunakan Flutter dan React Native.

🗄️ Database Management

Merancang dan mengelola database relasional (MySQL, PostgreSQL) dan NoSQL (MongoDB) untuk menyimpan data aplikasi dengan aman dan efisien.

🔒 Application Security

Mengimplementasikan security best practices, authentication, encryption, dan protection terhadap vulnerabilitas aplikasi.

⚙️ DevOps & Deployment

Mengdeployment aplikasi ke production, version control dengan Git, CI/CD pipeline, dan monitoring untuk aplikasi yang berjalan stabil.

Studio & Laboratorium

💻 Development Lab

Dilengkapi dengan workstation high-end, multiple monitors, dan perangkat development terkini untuk coding dan testing aplikasi.

🎨 Design Studio

Ruang kreasi dengan tools design seperti Figma, Adobe Creative Suite, dan whiteboard untuk brainstorming UI/UX design.

🖥️ Server Lab

Environment simulasi cloud dan server untuk praktik deployment, containerization dengan Docker, dan orchestration dengan Kubernetes.

📚 Resource Library

Perpustakaan digital dengan dokumentasi, tutorial video, coding challenges, dan resources untuk self-learning dan skill improvement.

🌐 High-Speed Internet

Koneksi internet fiber optic dengan bandwidth unlimited untuk development, testing, dan akses cloud services tanpa hambatan.

🤝 Collaboration Space

Ruang kerja kolaboratif dengan video conferencing, project management tools, dan whiteboard untuk teamwork dan agile development.

Kurikulum & Mata Pelajaran

Kelas X (Dasar)

  • Dasar Pemrograman (C, Python)
  • Algoritma & Struktur Data
  • Web Development Dasar (HTML, CSS)
  • Database Fundamentals
  • Sistem Operasi & Command Line

Kelas XI (Intermediate)

  • Object-Oriented Programming (OOP)
  • Web Development Advanced (PHP, JavaScript)
  • Mobile App Development
  • UI/UX Design Principles
  • API Development & Integration

Kelas XII (Advanced)

  • Full-Stack Web Development
  • Cloud Computing & Deployment
  • DevOps & CI/CD Pipeline
  • Software Testing & QA
  • Capstone Project & Magang

Sertifikasi Profesional

Siswa RPL memiliki kesempatan untuk mengambil ujian sertifikasi internasional yang diakui industri:

Oracle Java Programmer

Sertifikasi Java yang memvalidasi kemampuan dalam OOP, exception handling, dan pembuatan aplikasi Java enterprise-grade.

Microsoft Azure Developer

Sertifikasi cloud development yang mengakui keahlian dalam membangun, menguji, dan deployment aplikasi di Azure platform.

AWS Certified Associate

Sertifikasi Amazon Web Services untuk developer yang menguasai cloud infrastructure dan deployment di AWS ecosystem.

Google Cloud Professional

Sertifikasi Google Cloud yang membuktikan expertise dalam mengembangkan dan mengelola aplikasi di Google Cloud Platform.

Prospek Karir

Lulusan RPL memiliki peluang karir yang sangat luas di berbagai industri teknologi:

💼 Web Developer

Mengembangkan website dan aplikasi web untuk perusahaan, startup, atau agency dengan menggunakan teknologi terkini.

📱 Mobile App Developer

Menciptakan aplikasi mobile yang user-friendly untuk iOS dan Android, serta mengoptimalkan performa dan user experience.

🔙 Backend Engineer

Membangun sistem backend yang scalable, secure, dan efficient untuk mendukung aplikasi frontend dan mobile apps.

☁️ Cloud Solutions Architect

Merancang dan mengimplementasikan solusi cloud yang optimal, scalable, dan cost-effective untuk bisnis perusahaan.

🧪 QA Engineer / Tester

Melakukan testing komprehensif, quality assurance, dan automation testing untuk memastikan aplikasi berjalan optimal.

🚀 Tech Entrepreneur

Membangun startup tech, saas platform, atau aplikasi mobile sendiri dengan skills development yang kuat dan business acumen.
